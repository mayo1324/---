# אפליקציית לימוד שוק הון - אב טיפוס

אפליקציה ישראלית בעברית שמלמדת שוק הון לבני 15 ומעלה.

## הרעיון
- שיעור קצר של כ-10 דקות.
- אחריו תרגול על מקרה היסטורי: המשתמש מסמן כניסה, סטופ ויעד על גרף נרות, מריץ את הגרף ומקבל משוב (ירוק = נכון, אדום = טעות) וכוכבים.
- אין כסף אמיתי באפליקציה.

## אב הטיפוס (שלב נוכחי)
- דף אינטרנט אינטראקטיבי: HTML, CSS ו-JavaScript בלבד, ללא ספריות או build.
- מותאם לטלפון (390x844), עברית, RTL.
- מסכים: תרגול (גרף נרות, כניסה/סטופ/יעד, "הרץ את הגרף", רמז), משוב נכון, משוב שגוי.
- לא כולל: הרשמה, תשלום, מסך ראשי.
- מיועד לבדיקה עם בני נוער בטלפון.

## מבנה התיקייה
- `design/` - תמונות העיצוב (מקור האמת לעיצוב)
- `prototype/` - קוד אב הטיפוס (`index.html`, `style.css`, `app.js`)
